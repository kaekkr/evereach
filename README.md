## 📸 Overview

EveReach is an award-winning portfolio concept featuring fluid WebGL physics, GPU mesh canvas shaders, velocity-based scroll skews, and real-time 3D interactive procedural animations.

### ✨ Key Features

- **3D Cyber-Pup Studio:** Real-time procedural 3D dancing dog driven by Three.js & `@react-three/fiber` with dynamic tempo (BPM) and style toggles.
- **Fluid Physics Aura:** Viscous spring-driven spotlight aura that tracks cursor physics with heavy inertia.
- **GPU Liquid Mesh Canvas:** Low-overhead fragment-based ambient background lighting.
- **Velocity Scroll Skew:** Smooth dynamic viewport skewing relative to user scroll speed.
- **Command Palette (`Cmd + K`):** Instant search, shortcut navigation, and project estimator drawer.
- **Interactive Morphing Hero CTA:** Spring-based morphing button transitions on hover and tap.
